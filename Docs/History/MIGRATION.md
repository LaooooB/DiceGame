# 迁移约束与实现对照

## 目标

把已有游戏换到 Godot 4.6 stable Mono/.NET，仍是同一套游戏，而非借玩法重新制作。输入平台改为桌面，其他效果以原版为比对基准。GitHub 不在本次修改范围内。

## 原版到原生代码

| 原文件 / 内容 | Godot 工程中的消费者 | 保留要求 |
|---|---|---|
| `data/game.json`、`dice.json`、`upgrades.json` | `GameData`、`Simulation`、`GameApp`、`NativeRenderer` | 复制原字节，不调成长和波次曲线 |
| `math.js` | `MathEx`、`SeededRandom`、`Collision`、`SpatialGrid` | xorshift32、JS 舍入、扫掠碰撞和查询顺序 |
| `simulation.js` | `Simulation`、`RunState`、实体与事件模型 | 原时序、伤害、随机次数、弹丸快照、存档语义 |
| `app.js` | `GameApp`、`UiLayout`、`GameRoot` | 松手发射、拖动合成、弹窗暂停、场景流转 |
| `renderer.js` 静态美术 | `Assets/Reference`、`NativeArt` | 从原绘制函数导出，不用替代素材 |
| `renderer.js` 动态特效 | `EffectSystem`、`NativeRenderer` | 粒子随机种子、数量、寿命、速度、轨迹、颜色与触发顺序 |
| `audio.js` | `SoundSynth`、`NativeAudio` | 原音色公式、频率、衰减、变体、音量和节流 |
| 网页桌面外围 | `DesktopChrome` | 桌面侧栏及环境底色，保留游戏窄画布 |
| browser / WeChat 平台 API | `DesktopStorage`、`GameRoot` | 移除平台层；替换为原生窗口、输入、音频和存档 |

## 逻辑必须守住的内容

120Hz 固定步长来自 `Data/game.json`。渲染帧累计后最多执行 12 个步进，原版最大帧间隔裁切也保留。渲染不向模拟写回位置。所有核心数值使用 double；只有传给 Godot 的顶点、颜色、声音接口时转换。

扫掠检测不是 `RigidBody2D` / `CharacterBody2D`：两侧墙、顶边和敌人使用原本的最早碰撞规则。相同命中的排序、贴边修正、LastEnemy 防重复命中、单步碰撞迭代上限均照原处理。

发射快照保存类型、点数、伤害、特效和源位置。骰子合成、回收后不影响旧弹丸或已经排队的齐射。瞬时合成伤害不能掩盖持续数值变化。分裂只发生一代，拥挤时不悄悄删除本应发生的子弹伤害。

点数和类型不再新增独立机制。卡组变更对新一局生效，续局使用其保存的卡组。只取消触摸入口，不把拖动、松手规则改成自动射击。

## 原生绘制结构

桌面背景 → 游戏 SubViewport → 战场 SubViewport → 敌人及瞄准 → 加法混合弹丸 → 战斗特效 → 阵地 → 弹窗与提示。

游戏逻辑画布 432×864；实际离屏纹理使用 864×1728。战场裁切范围仍是原版 `(25,132,382,405)`。视口间用 Shader 做圆角，不改可碰撞范围。

`RoundedTexture.gdshader` 的 fragment 直接使用 `COLOR`，不再乘一次默认纹理：Godot CanvasItem 在 fragment 入口已经完成默认纹理乘色。重复相乘会使画面变暗。

`NativeRenderer` 没有依赖全局 Tween 时间；动态特效继续由原版计时公式驱动。暂停不推进战斗和粒子，菜单装饰时间可以继续。降低动态效果开关仍有效。

骰子图集包含九种参考尺寸，每张 6×6，行是六种类型、列是一至六点。图标是原版 20 个图标。动态缩放仍由原动画公式决定。大小变化时的抗锯齿、阴影采样与浏览器是否相同需要实际截图检验。

## 声音

纯函数 `SoundSynth.Synthesize` 每次按原版公式生成 float32 数组，可离开 Godot 单独比较全部样本。Godot 用原生音频生成器混合这些声音。音频帧缓存会带来设备相关延迟，不能以公式相同断言设备输出完全一致。

## 明确的桌面变化

触摸 / 微信适配不存在于运行时。增加 F11 全屏、右键取消、失焦暂停，提示文案改为鼠标。桌面外围由原生绘制重建，不再执行 CSS。浏览器存档改为 Godot 用户目录中的原子文件替换与备份。

没有读取浏览器 localStorage，也没有新增联机、排行榜、广告、付费、登录或服务器。

## 未闭环项

尚未实际编译和运行 Godot。源码及 API 对照不能证明没有编译错误。原生 SystemFont 与浏览器字体选取、文本基线和抗锯齿可能不同；外围阴影和渐变由原生图元重建，不能声称逐像素已一致。声音设备播放也未试听。

完整验收应由编译、固定种子状态、声音样本、原生截图、动态人工观察和真实鼠标交互共同完成。不要因浏览器旧测试通过就把 Godot 新工程标成通过。
